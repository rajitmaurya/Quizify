# Quizify

Quizify is a modern quiz application built using HTML, CSS, and JavaScript.  
It fetches real-time questions from an API and provides an interactive quiz experience with timer, progress tracking, and lifelines.

---

## Features

- Dynamic quiz questions from Open Trivia API
- Timer for each question
- Progress bar with question tracking
- Instant answer validation (correct / wrong)
- Sound feedback for answers
- Skip question lifeline (limited uses)
- Dark / Light mode toggle
- Responsive and modern glassmorphism UI

---

## Tech Stack

- HTML
- CSS (Glassmorphism + Animations)
- JavaScript (Vanilla JS)
- Open Trivia DB API
